이 저장소가 하는 일

pipeline

1 · 뼈대는 EndoTODAY

endotoday.com의 강의·아틀라스 230여 페이지를 수집해 7개 장으로 재편집했다. 각 장은 증례 이미지, 이미지–소견–치료 정리표, 연습문제를 갖는다.

2 · 살은 OneNote

내가 학회에서 정리한 노트(GI·Endo, 검진 protocol)를 MCP로 읽어 notes/에 마크다운으로 떨어뜨린다. 개인 메모·보험 같은 잡음은 규칙으로 걸러낸다.

3 · 출력은 웹 + PDF

합본 book.html을 인쇄해 PDF로 북마크까지 넣는다. 업데이트가 끝나면 다운로드 링크의 PDF가 같은 내용으로 다시 만들어진다.

  1. 동기화 — OneNote MCP로 학회노트 페이지를 읽는다 (tools/sync-onenote.md 절차).
  2. 정규화 — tools/onenote_to_md.py가 HTML을 마크다운으로 바꾸고 중복·잡음을 제거한다.
  3. 반영 — tools/build_notes.py가 notes/*.md를 워크북의 「학회노트」 장으로 렌더한다.
  4. 빌드 — tools/build_book.py → book.html → Chrome 인쇄 → downloads/EGD-workbook.pdf (북마크 주입).
  5. 배포 — master push → GitHub Actions → Pages.

EndoTODAY(endotoday.com, 이준행) 강의·아틀라스와 본인 OneNote 학회 정리를 기반으로 한 개인 학습용 정리. 원저작물의 권리는 원저자에게 있다.

약제·용량·기간은 실제 처방 관례와 학회 노트를 따른 것으로, 임상 적용 시 최신 가이드라인과 환자 상태를 반드시 확인할 것. 최종 판단과 처방은 면허 임상의의 몫이다.
