  • 심달: M1/M2/M3 · SM1/2/3 (m1/m2 = ESD 좋은 적응)
  • Lugol un-dyed area, NBI·EUS로 평가
  • SCC는 림프절 전이 양상이 특징적(경부·종격)
치료 (NCCN 2024 기반)
  • 조기(m1/m2) → ESD; 수술 범위: Ivor-Lewis, 3-field dissection(3영역 곽청)
  • 국소 진행성 → CROSS(카보플라틴+탁솔+41.4Gy) → 식도절제술
  • R0 절제면 가이드라인상 추가치료 없음 → 실제 adjuvant chemo 시행 多
  • 전이성 → fluoropyrimidine+platin ± pembrolizumab / trastuzumab

MALT 각론 — 병리 · 치료 심화

MALT lymphoma in depth
각론
개념 · 분류
  • WHO: extranodal marginal zone B-cell lymphoma of MALT
  • 과거 “high-grade MALToma” → 현재는 DLBCL로 통합
  • Dawson 기준(원발성 GI 림프종 정의)
  • 내시경 소견 비특이적 (발적·미란·종대·결절·궤양)
병리 5소견
  • 반응성 림프여포(Peyer’s patch 유사)
  • Marginal zone / monocytoid B세포
  • Lymphoepithelial lesion (LEL) — pancytokeratin으로 강조
  • 소림프구 + 형질세포 침윤
  • 소수의 centroblast / immunoblast
면역 · 분자
  • CD20/CD79a(+), CD43 aberrant, cyclin D1(−, mantle 배제)
  • 경쇄 제한(monoclonal), IgH 재배열
  • API2/MALT1 t(11;18) ~20% → 제균 반응 낮음
치료 (국내/ESMO)
  • 1차 H. pylori 제균 (병기 무관) → 6–8주 관해 평가
  • 불응/국한 → IFRT 24–30Gy; 전신 → 리툭시맙 ± R-CHOP
  • t(11;18) 양성 → 방사선 우선
실전 포인트
  • 확진 후 상급기관 의뢰 시 제균을 먼저 하지 말 것 (치료 판단에 영향)
  • Collision tumor(MALToma+adenocarcinoma) 가능
